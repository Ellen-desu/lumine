# Lumine HTTP Framework Guide

> **Lumine** is a lightweight, asynchronous HTTP web framework for Rust — built for simplicity, performance, and an ergonomic developer experience.

This repository hosts the [mdBook](https://rust-lang.github.io/mdBook/) source for the official **Lumine** documentation guide.

## 📖 Read the Guide

The guide covers the following topics:

| Chapter | Description |
|---|---|
| **Introduction** | Overview, motivation, and key features |
| **Installation & Quick Start** | Adding dependencies and your first "Hello, World!" server |
| **Routing & Parameters** | Static routes, dynamic path params (`:id`), and query params |
| **Request** | Reading headers, body, and JSON payloads via `serde` |
| **Response** | Using the `IntoResponse` trait, status codes, and file streaming |
| **Middleware** | Adding cross-cutting concerns like logging, auth, and CORS |
| **Error Handling** | Ergonomic error propagation and global error handlers |
